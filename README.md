# stueam.github.io

Bojun Yang's personal homepage and online resume.

GitHub Pages homepage: [https://stueam.github.io/](https://stueam.github.io/)

The favicon is a deep-blue NY monogram for Nick Yang.

The footer displays site visitors (UV) and page views (PV) using
[Busuanzi](https://www.busuanzi.cc/doc.php). Counts are stored by the
service and start when tracking is enabled; earlier traffic cannot be recovered.
Tracking runs only on `stueam.github.io`, so local previews do not send counting
requests. Hash-based navigation between tabs does not add another page view;
opening or reloading the page does. Counter labels stay hidden until the service
returns data, and remain hidden if it is unavailable or blocked.
Visitor deduplication follows the provider's rules; repeat visits from the same
visitor within one day count once toward UV. UV is not a lifetime count of unique people.
